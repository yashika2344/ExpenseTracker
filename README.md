# ExpenseTracker

# 💸 Expense Tracker Application

A full-stack Java-based web application for managing and tracking personal expenses and budgets. Built using Spring Boot, Thymeleaf, and MySQL, this application helps users log expenses, set weekly budgets, and generate reports for financial insights.

---

## 📌 Features

- ✅ User-friendly UI with Thymeleaf and Bootstrap
- 🧾 Add, view, and categorize expenses
- 📊 Weekly budget setting and tracking
- 🔔 Automatic budget-exceeded notifications
- 📅 Date-based expense logging
- 🗂️ Report generation (future scope)

---

## 🏗️ Architecture

Follows the **Model-View-Controller (MVC)** architecture:

- **Model**: Java classes representing `Expense`, `Budget`, and `User`
- **View**: Thymeleaf templates styled with Bootstrap
- **Controller**: Handles user input and business logic (`ExpenseController`, `BudgetController`)

---
